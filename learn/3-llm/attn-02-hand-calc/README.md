# 注意力 02：手算一遍

**目标**：不靠任何库，用纸笔把一次注意力从头算到尾。算过一遍，后面所有公式都不再是符号。

**配套**：[互动手算器](demo/index.html)（改数字、点开每一格看算式、练习模式自己填再检查）· NumPy 对照：[`../attn-07-from-scratch/`](../attn-07-from-scratch/)（待做）。

**前置**：会做矩阵乘法即可。第 1、2 层不需要。

---

## 第 1 层 · 一句话

注意力 = 每个词拿自己的“问题”(q) 去和每个词的“标签”(k) 比相似度，把相似度变成百分比，再按百分比把每个词的“内容”(v) 混合起来。

## 第 2 层 · 白话

想象你在读“猫追鱼”，读到“追”时想知道：这个动作和谁有关？你会回头扫一遍整句话，给每个词一个“相关程度”的分，再把相关程度高的词的信息多记一点。注意力把这个过程变成了一串矩阵运算。

---

## 第 3 层 · 手算（本章主体）

### 题目

3 个词：猫、追、鱼。每个词一个 2 维向量（每行一个词）：

$$
X=\begin{bmatrix}1&0\\0&1\\1&1\end{bmatrix}
$$

三个投影矩阵（2×2）：

$$
W_Q=\begin{bmatrix}1&0\\1&1\end{bmatrix},\quad
W_K=\begin{bmatrix}1&1\\0&1\end{bmatrix},\quad
W_V=\begin{bmatrix}1&0\\0&2\end{bmatrix}
$$

$d_k=2$。问：三个词读完整句话后的新表示 $O$ 是什么？

### 步骤 1–3：算 Q、K、V

矩阵乘法：结果第 $i$ 行第 $j$ 列 = $X$ 的第 $i$ 行与 $W$ 的第 $j$ 列的点积。

以 $Q$ 的第 3 行（鱼）为例：$[1,1]\cdot$ 第 1 列 $[1,1]=1\times1+1\times1=2$；$[1,1]\cdot$ 第 2 列 $[0,1]=0+1=1$。所以鱼的 $q=[2,1]$。

$$
Q=XW_Q=\begin{bmatrix}1&0\\1&1\\2&1\end{bmatrix},\quad
K=XW_K=\begin{bmatrix}1&1\\0&1\\1&2\end{bmatrix},\quad
V=XW_V=\begin{bmatrix}1&0\\0&2\\1&2\end{bmatrix}
$$

### 步骤 4：打分 $S=QK^\top$

$S_{ij}=q_i\cdot k_j$。例：$S_{\text{追},\text{鱼}}=q_{\text{追}}\cdot k_{\text{鱼}}=[1,1]\cdot[1,2]=1+2=3$。

$$
S=\begin{bmatrix}1&0&1\\2&1&3\\3&1&4\end{bmatrix}
$$

### 步骤 5：缩放 $S'=S/\sqrt{d_k}$，$\sqrt2\approx1.414$

$$
S'\approx\begin{bmatrix}0.707&0&0.707\\1.414&0.707&2.121\\2.121&0.707&2.828\end{bmatrix}
$$

### 步骤 6：取指数 $E=e^{S'}$，并算每行的和

| | 猫 | 追 | 鱼 | 行和 |
|---|---|---|---|---|
| 猫 | 2.028 | 1.000 | 2.028 | 5.056 |
| 追 | 4.113 | 2.028 | 8.342 | 14.484 |
| 鱼 | 8.342 | 2.028 | 16.919 | 27.289 |

### 步骤 7：每行除以行和（softmax）$A$

例：$A_{\text{追},\text{鱼}}=8.342/14.484=0.576$。**每一行的和是 1**，可以拿来自查。

$$
A\approx\begin{bmatrix}0.401&0.198&0.401\\0.284&0.140&0.576\\0.306&0.074&0.620\end{bmatrix}
$$

### 步骤 8：加权求和 $O=AV$

例：$O_{\text{追}}=0.284\,v_{\text{猫}}+0.140\,v_{\text{追}}+0.576\,v_{\text{鱼}}=0.284[1,0]+0.140[0,2]+0.576[1,2]=[0.860,\ 1.432]$。

$$
O\approx\begin{bmatrix}0.802&1.198\\0.860&1.432\\0.926&1.389\end{bmatrix}
$$

### 怎么读结果

- “追”这一行 $A$ 里，“鱼”的权重最大（0.576）：因为 $q_{\text{追}}\cdot k_{\text{鱼}}$ 的分数最高。
- 所以“追”的新表示 $O_{\text{追}}$ 里，“鱼”的 $v$ 占了最大份额。
- 注意：这里的数字是为了好算特意挑的。没有哪个“语义”对应它们，机制才是重点。

## 第 4 层 · 数学：手算背后的三条规则

**① 矩阵形状**：$X$ 是 $3\times2$，$W$ 是 $2\times2$，$XW$ 是 $3\times2$。内侧的 2 必须相等，结果取外侧。$QK^\top$ 是 $(3\times2)(2\times3)=3\times3$，所以分数表一定是“词数 × 词数”。

**② softmax 按行**：对 $S'$ 的每一行单独归一化。行 $i$ 的权重回答的是“第 $i$ 个词该怎么分配注意力”。如果误按列做，含义就变了。

**③ softmax 对平移不变**：$\mathrm{softmax}(z)=\mathrm{softmax}(z-c)$（对任意常数 $c$）。

推导：$\dfrac{e^{z_i-c}}{\sum_j e^{z_j-c}}=\dfrac{e^{-c}e^{z_i}}{e^{-c}\sum_j e^{z_j}}=\dfrac{e^{z_i}}{\sum_j e^{z_j}}$。

这条规则的用处：实现时先把每行减去该行最大值再取指数，防止 $e^{z}$ 溢出。例如 $z=1000$ 时 $e^{1000}$ 会得到无穷大，而 $e^{1000-1000}=1$ 就没问题。结果不变。

## 第 5 层 · 代码

整段手算，用 NumPy 就是几行：

```python
import numpy as np

def attention(X, Wq, Wk, Wv):
    Q, K, V = X @ Wq, X @ Wk, X @ Wv                  # 步骤 1-3
    S = Q @ K.T / np.sqrt(K.shape[-1])                # 步骤 4-5
    S = S - S.max(axis=-1, keepdims=True)             # 防溢出（规则 ③）
    E = np.exp(S)                                     # 步骤 6
    A = E / E.sum(axis=-1, keepdims=True)             # 步骤 7，按行
    return A @ V, A                                   # 步骤 8
```

上面的题目输入这段代码，得到的 $A$ 和 $O$ 与手算一致（已用 NumPy 2.0.2 对照检查，误差在 1e-3 以内）。

## 练习

**练习 1（手算）**：$X=\begin{bmatrix}2&0\\1&1\\0&1\end{bmatrix}$，$W_Q,W_K,W_V$ 同上，$d_k=2$。算出 $Q,K,V$ 和 $S'$。

**练习 2（判断）**：下列哪些说法正确？
(a) $A$ 的每一列和为 1；(b) $A$ 的每一行和为 1；(c) 把 $S'$ 的所有数同时加 10，$A$ 不变；(d) 把 $S'$ 的所有数同时乘 10，$A$ 不变。

**练习 3（概念）**：如果去掉“除以 $\sqrt{d_k}$”这一步，本题的 $A$ 会更“平均”还是更“尖”？为什么？

**练习 4（动手）**：在[手算器](demo/index.html)里把 $W_Q$ 改成单位阵 $\begin{bmatrix}1&0\\0&1\end{bmatrix}$，观察“追”的注意力分配怎么变。

### 答案

**练习 1**：$Q=\begin{bmatrix}2&0\\2&1\\1&1\end{bmatrix}$，$K=\begin{bmatrix}2&2\\1&2\\0&1\end{bmatrix}$，$V=\begin{bmatrix}2&0\\1&2\\0&2\end{bmatrix}$；$S'=S/\sqrt2\approx\begin{bmatrix}2.828&1.414&0\\4.243&2.828&0.707\\2.828&2.121&0.707\end{bmatrix}$。继续算可得第一行 $A\approx[0.768,0.187,0.045]$。

**练习 2**：(b)、(c) 正确。(a) 错，是每行；(d) 错，乘 10 会让分布更“尖”，$A$ 会变。

**练习 3**：更“尖”。分数没缩小，数值更大，softmax 更倾向把权重集中到最大的那一个。$d_k$ 越大这个效应越强，详见后续《softmax 与 √d》。

**练习 4**：自己试，没有标准答案；重点是看到 $q$ 的变化如何通过点积影响权重。

## 易错点

- **忘记 $K^\top$**：$QK$ 的形状对不上；一定是 $QK^\top$。
- **softmax 方向错**：应沿“被看的词”那个维度（每行），不是沿“提问的词”。
- **以为 $A$ 对称**：$A_{ij}\ne A_{ji}$。“追”看“鱼”的权重（0.576）不等于“鱼”看“追”的权重（0.074）。

# 基础 C：掩码与位置

**读完你会知道**：为什么生成文字时要掩码、注意力为什么“看不见”词序、最初的位置编码怎么做。

**前置**：[基础 A：注意力基础](../01-attention/)。

**配套**：[互动版](demo/index.html)（可打乱词序、开关掩码和位置编码）· [TikTok 图卡 6 张](cards/out/)。

> 玩具模型：矩阵为人工设定。位置编码的底数取 100 并乘 0.5，是为了在 6 维、短句里看清差异，不是论文原值。

## 1. 因果掩码：不许偷看后面

生成文字时，第 $i$ 个词只能看第 1 到第 $i$ 个词。做法：打分之后、softmax 之前，把“未来位置”的分数设为 $-\infty$：

$$
s_{ij}\leftarrow -\infty\quad(j>i),\qquad a_{ij}=\mathrm{softmax}_j(s_{ij})
$$

$e^{-\infty}=0$，所以未来位置的权重恰好是 0，且每一行仍然和为 1。互动版里被屏蔽的格子显示为灰色。

**为什么训练时需要它**：训练时，模型一次并行地预测每个位置的下一个词：看到「小猫」预测「没有」，看到「小猫 没有」预测「过」，……如果不加掩码，第 $i$ 个位置能直接看到第 $i+1$ 个词，那正是它要预测的答案，预测就成了抄答案。互动版的第一部分把这些预测逐行列出，关掉掩码就能看到“答案已泄露”。

**哪些模型用**：GPT 这类逐字生成的模型用因果掩码；BERT 这类需要双向理解的模型不用（它看整句）。

## 2. 位置：注意力本身看不见词序

不加掩码时，注意力对输入顺序是“等变”的：把词打乱，每对词之间的权重不变，只是行和列跟着换了位置。原因很直接：打分只用到词向量本身（$q_i\cdot k_j$），其中没有任何“它在第几个”的信息。

互动版的第二部分可以验证：点“打乱词序”，看“同一对词的权重，最大变化”——没有位置编码时是 0.0000。

对语言来说，“小猫追狗”和“狗追小猫”词一样、顺序不同、意思相反，所以必须把位置信息加进来。

## 3. 最初的做法：正弦位置编码

给每个位置 $pos$ 一个固定向量，加到词向量上（Vaswani et al., 2017）：

$$
PE_{(pos,2j)}=\sin\!\left(\frac{pos}{10000^{2j/d}}\right),\qquad
PE_{(pos,2j+1)}=\cos\!\left(\frac{pos}{10000^{2j/d}}\right)
$$

不同维度用不同频率的正弦/余弦，所以每个位置的向量都不一样，且相对位置有规律可循。加上之后，同样的词在不同位置会得到不同的向量，注意力权重就会随顺序变化。互动版里勾选“加上位置编码”，再打乱词序，最大变化不再是 0。

## 4. 没讲的

- 现代大模型更常用旋转位置编码（RoPE）等做法，不是把位置向量“加”到词向量上，而是在算 $q\cdot k$ 时让位置体现为旋转。本章只讲最初的正弦版本。
- 可学习的位置编码：让位置向量也由训练得到。

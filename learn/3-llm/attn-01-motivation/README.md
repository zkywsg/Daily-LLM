# 注意力 00：为什么要发明注意力

**读完你会知道**：循环网络（RNN）读长句子时卡在哪、注意力怎么绕开这个瓶颈、两者在“路径长度”和计算量上差在哪，以及注意力付出的代价。

**前置**：知道神经网络“输入 → 输出”即可。

**配套**：[互动版](demo/index.html)（路径长度、梯度衰减、n 与 d 的计算量交叉点）· [TikTok 图卡](cards/out/)。

## 第 1 层 · 一句话

RNN 把整句话一步一步压进同一个向量，远处的信息要走很多步才能传到；注意力让每个词一步直达任何别的词，代价是要算词与词之间的 $n\times n$ 张表。

## 第 2 层 · 白话

想象传话游戏：一句话要从第 1 个人传到第 50 个人，每人转述一次，传到最后多半走样。RNN 就是这样的传话：第 $t$ 个词的信息要经过 $t$ 次转述才能影响末尾。注意力换了种做法：每个人都能直接举手问任何人，不用经过中间人。

早期翻译模型的做法是把整句英文压成一个固定长度的向量再交给解码器翻译，Bahdanau 等人（2014）指出这是瓶颈，让解码器在每一步“回头看”源句的各个词，并学习该看哪里。这就是注意力的起点。

## 第 3 层 · 手算

**信息传递距离**：句子有 $n$ 个词，第 1 个词想影响第 $n$ 个词。

| 结构 | 需要经过的步数 |
|---|---|
| RNN | $n-1$ |
| 注意力 | 1（直接打分，直接取值） |

**梯度怎么衰减**：最简单的标量 RNN：$h_t=\tanh(w\,h_{t-1}+u\,x_t)$。第 0 步输入对第 $T$ 步状态的影响（链式法则）：

$$
\frac{\partial h_T}{\partial x_0}\;\propto\;\prod_{t=1}^{T} w\,\big(1-h_t^{2}\big)
$$

每个因子是 $w(1-h_t^2)$，而 $1-h_t^2\le 1$。若 $|w|<1$，连乘后指数级趋近 0（梯度消失）；若 $|w|$ 大，则可能指数级爆炸。互动页第 2 节用固定输入序列把这个乘积画出来。

## 第 4 层 · 数学推导

**(1) 向量形式**

$h_t=\tanh(W_h h_{t-1}+W_x x_t)$，雅可比 $\partial h_t/\partial h_{t-1}=\mathrm{diag}(1-h_t^2)\,W_h$。跨 $T$ 步：

$$
\frac{\partial h_T}{\partial h_0}=\prod_{t=1}^{T}\mathrm{diag}(1-h_t^{2})\,W_h
$$

乘积的范数大致随 $T$ 指数增长或衰减，取决于 $W_h$ 的谱半径与激活函数的饱和程度。LSTM / GRU 用门控缓解这个问题，但路径长度仍是 $O(n)$。

**(2) 注意力的路径长度**

输出 $o_i=\sum_j a_{ij}v_j$，位置 $j$ 的值直接乘权重进入位置 $i$，路径长度 1。

**(3) 复杂度对比**（Vaswani et al. 2017，Table 1）

| 层类型 | 每层计算量 | 顺序操作数 | 最大路径长度 |
|---|---|---|---|
| 自注意力 | $O(n^2\cdot d)$ | $O(1)$ | $O(1)$ |
| 循环 | $O(n\cdot d^2)$ | $O(n)$ | $O(n)$ |

含义：
- 注意力可以在位置维度上并行（顺序操作数 $O(1)$），适合 GPU；RNN 必须一步等一步。
- 计算量比较取决于 $n$ 与 $d$：$n<d$ 时注意力每层更省，$n>d$ 时更贵。长上下文时 $n^2$ 项成为主要矛盾，这引出后面的 KV cache、FlashAttention 等优化。

**(4) 代价**

- 要保存 $n\times n$ 的分数表（空间 $O(n^2)$）。
- 注意力本身不含位置信息，要额外注入（见注意力 06）。
- 生成时要保证只看过去（掩码，见基础 C）。

## 第 5 层 · 代码与练习

```python
import numpy as np

def rnn_influence(w, u, xs):
    """标量 RNN 中，x_0 对每个 h_T 的影响 |dh_T/dx_0|。"""
    h, J, out = 0.0, None, []
    for t, x in enumerate(xs):
        h = np.tanh(w * h + u * x)
        d = (1 - h * h)
        J = u * d if t == 0 else J * w * d
        out.append(abs(J))
    return out

xs = np.random.default_rng(0).standard_normal(50)
print([f"{v:.1e}" for v in rnn_influence(0.8, 1.0, xs)[::10]])
```

**练习**

1. $n=64,\ d=512$：自注意力与 RNN 每层计算量（只比 $n^2d$ 与 $nd^2$）谁大？大多少倍？
2. 为什么 $w$ 略大于 1 的 RNN 也不一定梯度爆炸？
3. 注意力的“最大路径长度 $O(1)$”是否意味着它一定比 RNN 学得好？

**答案要点**

1. $n^2d=64^2\cdot512=2{,}097{,}152$，$nd^2=64\cdot512^2=16{,}777{,}216$；RNN 大 8 倍（$d/n=8$）。
2. $\tanh$ 饱和时 $1-h_t^2$ 很小，抵消了 $w>1$。
3. 不。路径短只是让信息容易传递，学习效果还取决于数据、规模、优化等。

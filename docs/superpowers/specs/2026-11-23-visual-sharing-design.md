# 设计文档：学习、TikTok、GitHub 三出口的统一内容流水线

**状态**：已落地（2026-11-26）。实际目录与本文第 3、4 节的草案不同：新内容放在 `learn/<层>/<知识点>/`（讲解 `README.md`、`demo/`、`cards/`），共享脚本在 `learn/3-llm/_shared/`；注意力系列 13 个知识点已完成。发布用 `learn/build-site.mjs` + `.github/workflows/pages.yml`。旧的 19 个家族与 `foundations/` 已于 2026-11-26 归档到 `_archive/v1/`。

## 1. 目标

同一份内容服务三个目的：

| 目的 | 需求 | 形式 |
|---|---|---|
| 自己从 0 学到大模型 | 写得快、改得轻、公式和代码好用、不被平台绑定 | 仓库内 Markdown |
| TikTok 图文分享 | 一眼抓人、一图一点、可批量出图 | 竖版 PNG 图卡轮播 |
| GitHub 分享 | 陌生人 10 秒内看懂并能读下去，打开成本最低 | 仓库 md 为主阵地，GitHub Pages 为互动增强 |

## 2. 核心原则

1. **一份源，多出口**：每个知识点只维护一份 md 和一份图源码，其余产物由它生成。
2. **GitHub 上直接可读**：主体内容不依赖 Pages，Pages 挂了也不影响阅读。
3. **Artifact 不进分享路径**：只在制作阶段用来做原型和预览。原因：读者是否需要登录 claude.ai 未验证，且内容主副本不应放在平台上。
4. **学习即生产**：学完一个点，整理成 md + 图，同时得到三个出口的素材。

## 4. 内容单元："一个知识点"

```
<章节目录>/
  xx-topic.md              # 正文（GitHub 直接渲染，公式用 $...$，图引用 assets/）
  assets/
    xx-topic-<图名>.svg    # 图源码，同时被 md 引用
  cards/
    xx-topic/              # 该知识点的 TikTok 图卡
      card.html            # 图卡源码（多张，由一个模板生成）
      out/01.png ... 0N.png
  demo/
    xx-topic.html          # 互动版（纯前端，供 Pages 使用）
```

现有家族已有 `assets/*.svg`，直接沿用，不重画。

## 5. TikTok 图卡规格（草案）

- 一组 5–8 张，竖版。
- 第 1 张：钩子（反直觉结论或数字）+ 最有冲击力的一张图。
- 中间 3–5 张：每张一个点，一图加一两句话。
- 最后一张：一句总结，加站点名或短网址。图文内不能放可点击链接，引流靠主页简介。
- 用 HTML/SVG 模板写，无头浏览器批量截成 PNG，改文字或配色后一条命令重出。
- **待核对**：TikTok 图文当前推荐尺寸、张数上限、文字安全区。制作第一组前先查官方说明，不凭记忆定。

## 6. GitHub 分享形式

两层：

1. **仓库本身（主阵地）**
   - README 顶部放路线图封面图，下接五层学习路线和各章入口。
   - 章节 md 内嵌图，公式用 GitHub 支持的数学语法，示意图可用 mermaid。
   - 零门槛，不依赖托管。
2. **GitHub Pages 站点（增强）**
   - 放 `demo/` 里的互动版，加搜索和导航。
   - README 放"在线互动版"链接。
   - 现有 `web/` 时间线并入站点，不再单独维护。

不采用：PDF 作主形式（仅可按章节选做下载）；Artifact 链接作公开入口。

## 7. 推进顺序

1. 确认本设计（含目录落点、章节清单）。
2. 做第一个知识点，建议 **注意力机制**（`foundations/08-attention-mechanism`），把 md、图、图卡、互动版四个产物跑通一遍。
3. 看图卡与互动版效果、TikTok 反馈，再决定铺开节奏。
4. 回头补第 0、1、4 层内容；其余家族逐个补图卡与互动版。

按项目 CLAUDE.md 分档：本设计属于重型流程；步骤 2 之后每个知识点按中型流程做。

## 8. 未验证事项与风险

- TikTok 图文规格、读者在 TikTok 上的反应：未知，靠第一组试验。
- GitHub 对数学公式与 mermaid 的渲染细节：做第一个知识点时实测。
- Pages 站点技术选型（VitePress / Starlight / 纯静态）：第一个知识点跑通后再定，不预先搭。
- 新写的第 0、1、4 层工作量大，范围和节奏需要作者另行决定。
- Artifact 能否被未登录读者打开：未验证，不作为公开入口的依据。
